# 灵犀评测集 · 标注规范

这份规范定义“什么算对”。评测集里的每一条都按这里的定义标注；规则引擎和大模型都按同一套定义被打分。
撰写与标注评测集的人只看这份规范，不看规则代码、词表和已有的评测条目。

场景：美妆品牌的线上客服。消费者通过文字进线，人工坐席回复。评测两类文本：

- **消费者消息**（A 类）：标注意图、情绪、风险。
- **坐席回复**（B 类）：标注这句话能不能直接发出去。

## A 类 · 消费者消息

每条消息是消费者单独发来的一句或两句话，没有上下文、没有订单和档案。**只根据文字本身标注**。

### A1 意图 `intents`

写 1 个主意图；如果这句话确实同时在做两件事，可以再写 1 个，主意图放在第一位。不要为了保险多写。

| 取值 | 含义 | 典型说法 |
|---|---|---|
| `pre_sale_consult` | 售前咨询：选品、对比、库存、补货、规格 | 哪款好、有没有、什么时候到货 |
| `product_efficacy` | 功效咨询：问“有没有用”“能不能达到某效果” | 能淡斑吗、多久见效 |
| `usage_guidance` | 使用指导：用法、顺序、用量、频次、能否叠加 | 先用哪个、一次几泵 |
| `skin_matching` | 适配咨询：某种肤质、某类人群（孕期、哺乳期、术后、某年龄）能不能用 | 敏感肌能用吗 |
| `authenticity` | 真伪与品质质疑：假货、批号、防伪、生产日期、包装被拆、质地气味与以往不同 | 是不是正品 |
| `logistics` | 物流：发货、配送进度、签收异常、指定时间送达 | 怎么还没到 |
| `return_refund` | 退换与退款：退货、换货、取消订单、退款进度 | 我要退 |
| `adverse_reaction` | 不良反应：使用后身体出现不适（皮肤、眼、唇等） | 用完脸红肿 |
| `complaint` | 投诉与不满：对服务、流程、态度、处理结果不满；要求升级；表示放弃 | 我要投诉 |
| `price_promo` | 价格与优惠：活动、优惠券、保价、差价、赠品、议价 | 能便宜点吗 |
| `membership` | 会员权益：积分、等级、会员礼、专属顾问 | 积分怎么少了 |
| `gift_consult` | 送礼：为他人选礼物、礼盒、贺卡 | 送妈妈选哪个 |
| `other` | 以上都不是：寒暄、致谢、确认、发票等事务 | 好的、谢谢 |

判断要点：

- 使用后出现不适并且在陈述这件事 → `adverse_reaction`；只是说自己是敏感肌、想选温和的产品 → `skin_matching` 或 `pre_sale_consult`。
- 退款迟迟不到账是 `return_refund`，不是 `logistics`。
- 一句话既在办事又在发火（“退了三次都没退成”）：办的事是主意图，可以把 `complaint` 写成第二个。纯粹在表达不满、没有具体业务 → `complaint`。

### A2 情绪 `emotions`

写 1 个主导情绪；确实并存时可再写 1 个，主导的放第一位。

| 取值 | 含义 |
|---|---|
| `anger` | 愤怒：指责、质问、威胁、反讽 |
| `anxiety` | 焦虑：担心、着急、害怕、不确定 |
| `sadness` | 低落：失望、心灰意冷、放弃 |
| `grievance` | 委屈：觉得被不公平对待、被忽视、反复折腾 |
| `calm` | 平静：就事论事，没有明显情绪 |
| `anticipation` | 期待：有兴趣、想买、盼着结果 |
| `joy` | 愉快：开心、惊喜、满意 |
| `gratitude` | 感谢 |

判断要点：反讽按真实情绪标（“你们服务可真好，三天没人理”是 `anger` 或 `grievance`，不是 `joy`）。普通提问默认 `calm`；带着明显兴趣或盼望的提问可以标 `anticipation`。

### A3 风险 `risks`

只标**从文字本身就能看出、值得坐席立即留意**的风险；没有就写空数组。可以多个。

| 取值 | 什么时候标 | 什么时候不标 |
|---|---|---|
| `safety` | 消费者陈述使用后身体出现了不适或损伤 | 只是询问会不会过敏；说自己肤质敏感 |
| `pr` | 已经或威胁在公开渠道传播：社交平台发帖、找媒体或记者、找博主、说“全网都在说” | 只是提到在某平台看到种草才买的 |
| `legal` | 提到投诉监管部门、消协、12315、起诉、律师、做鉴定追责 | 一般性地说“我要投诉你们客服” |
| `churn` | 明确表示以后不再购买、要离开这个品牌，或带着放弃的口气终止沟通 | 只是说不满意 |
| `minor` | 使用者或提问者是未成年人（未满 18 岁；年龄、年级、“给孩子用”都算） | 提到孩子但产品不是给孩子用 |
| `fraud` | 直接索要高倍数赔偿（退一赔三、假一赔十等）或开口要赔偿金 | 正常申请退款 |
| `privacy` | 消费者要求发送或公开他人的个人信息，或主动贴出身份证号等高度敏感信息 | 报订单号、手机号后四位 |

`regulatory`、`service` 两类需要结合业务数据才能判断，评测集里不标。

## B 类 · 坐席回复

每条是坐席准备发给消费者的一句话。标注 `block`：这句话**是否必须拦下、不能原样发出**。

必须拦下（`block: true`）的六种情况：

1. **医学诊断**：替消费者判断得了什么病或是不是过敏（“您这是过敏”“看着像皮炎”）。
2. **宣称医疗作用**：说产品能治疗、消炎、杀菌、根治，或称产品为“药妆”。
3. **绝对化的安全或效果保证**：“绝对不会过敏”“百分百安全”“保证有效”“没有任何副作用”。
4. **核查前推卸责任**：还没核查就断言与产品、品牌无关，或以“不是质量问题”为由拒绝处理。
5. **指责消费者**：把问题归咎于消费者自己的用法、肤质或操作。
6. **以利益换评价**：以退款、补偿为条件要求删除差评、撤回帖子或投诉；好评返现。

不需要拦下（`block: false`）：

- 合规、克制的表述：建议停用并就医、说明“我们不能判断是否过敏”、说明备案功效、“预计”送达。
- 只需提醒、不必拦截的问题：最高级形容（“最好的面霜”）、承诺具体送达时刻、明文写出完整手机号。
- 看起来像违规、其实不是的句子：否定句（“这不是您的问题”“我们不能保证”）、转述消费者的话、说明规则本身（“我们不会要求您删除评价”）。

## 难度

评测集要包含相当比例不容易的条目，否则数字没有意义：

- 口语、网络用语、错别字、不完整的句子；
- 没有出现任何关键词的含蓄表达（“这是最后一次了”）；
- 反讽；
- 否定与转述（“不是过敏，就是想问问顺序”“我朋友说她用了过敏，我能用吗”）；
- 出现了风险词但其实没有风险（“在小红书上被种草的”“我是律师，平时很忙，想买个省事的”）；
- 一句话里有两个意图。
